Project 1: Pesa Shield Kenya

Project Overview

Pesa Shield Kenya is a machine learning project designed to help users identify potentially fraudulent SMS messages and distinguish them from legitimate messages.

The project focuses on common scams affecting Kenyans, including fraudulent mobile money messages, fake job offers, loan scams, phishing messages, fake promotions, and messages attempting to steal personal information.

Problem Statement

Many people receive suspicious messages that attempt to trick them into sending money or sharing confidential information. These messages can sometimes appear genuine.

Pesa Shield Kenya aims to address this problem by analysing message text and identifying patterns associated with scams.

Project Objectives

  • Develop a system for classifying SMS messages.
  • Distinguish potentially fraudulent messages from legitimate messages.
  • Use machine learning to analyse message text.
  • Identify different categories of scams.
  • Warn users about suspicious messages.
  • Promote awareness of mobile communication fraud.

Planned Features

  • Message input and analysis.
  • Scam and legitimate message classification.
  • Detection of suspicious words and patterns.
  • Display of prediction results.
  • Explanation of potential warning signs.

Dataset

The project is planned around a dataset containing more than 50,000 messages, with a target of 60,000 messages divided into 30,000 scam messages and 30,000 legitimate messages.

The dataset is intended to cover different scam categories and legitimate communications.

Technologies

  • Python
  • Pandas
  • Scikit-learn
  • Machine Learning
  • Natural Language Processing
  • HTML

Project 2: Research Proposal RAG System

Project Overview

The Research Proposal RAG System is a project designed to help university students find, access, and retrieve relevant information from academic research proposals and other research documents.

The system focuses on academic research rather than general documents or stories. It aims to make it easier for students to discover relevant research materials.

Problem Statement

University students may find it difficult to locate relevant research proposals and extract useful information from large collections of PDF documents.

This project aims to organise research documents and use information retrieval techniques to help students find relevant academic material.

Project Objectives

  • Provide access to academic research proposals.
  • Organise research documents in a central repository.
  • Allow students to search for research topics.
  • Extract and process text from PDF documents.
  • Use embeddings to represent document content.
  • Retrieve relevant document sections.
  • Explore Retrieval-Augmented Generation.

Planned Features

  • Research document repository.
  • PDF document ingestion.
  • Text extraction and document chunking.
  • Creation of document embeddings.
  • Semantic search.
  • Retrieval of relevant research passages.
  • Potential integration of a language model.

How the System Works

  1. Research proposals are added to the document collection.
  2. The system extracts text from the documents.
  3. The extracted text is divided into smaller chunks.
  4. Embeddings are generated for the text chunks.
  5. The embeddings are stored for retrieval.
  6. A student submits a research question.
  7. The system retrieves relevant document sections.
  8. A language model can use the retrieved information to generate an answer.

Technologies and Concepts

  • Python
  • Jupyter Notebook
  • Document Processing
  • Text Embeddings
  • Semantic Search
  • Information Retrieval
  • Large Language Models
  • Retrieval-Augmented Generation
  • Git and GitHub

Project Status: Initial repository setup and development planning.

Project 3: Malware Detection and Device Behaviour Prediction

Project Overview

This project explores the use of data analysis and machine learning to identify potentially malicious software by analysing relevant features and behaviour.

The project investigates how data can be used to distinguish potentially harmful software from non-malicious software.

Problem Statement

Malicious software can threaten the security of computers and other digital devices. Analysing relevant data can help identify patterns associated with potentially harmful software.

Project Objectives

  • Explore available malware-related datasets.
  • Identify useful features for analysis.
  • Prepare and process data for machine learning.
  • Investigate patterns associated with malicious behaviour.
  • Develop a model to classify potentially malicious software.
